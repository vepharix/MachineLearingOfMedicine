## 一、事实性缺陷（泄漏 / 纪律 / 统计方法）

### 没问题（先把纪律和 smearing 核完）

**Train / val / test 纪律：没问题。** `t2_fit.py` 只构造 `tr`/`va`（L16），网格按 val MAE 选超参（L46–49），`joblib.dump` 冻结（L60）；`t2_eval.py` 读冻结模型，test 只走一遍（L31–45）。`make_regressor`（`common.py` L112–125）用 `Pipeline(SimpleImputer → StandardScaler → 模型)`，fit 只发生在 `X.loc[tr]`，与 T1 同一套闸。基线中位数/均值取 train（`t2_fit.py` L25–27；`t2_eval.py` L27–29），没有用 val/test 的中心统计量。

**Smearing 公式与用法：没问题。** 目标是 `log(y+1)=f+r`，因此  
`E[y+1]=exp(f)·E[exp(r)]` ⇒ `ŷ=exp(f)·S−1`。  
`smearing_factor`（`common.py` L135–137）是 `mean(exp(r))`，残差方向是 `ylog - predict`（`t2_fit.py` L57），S 只在 train 上算、写入报告，test 用冻结 S（`t2_eval.py` L42–44）。`smear=1` 走 `exp(f)−1`（中位数/几何均值型，给个体 MAE），`smear=S` 抬回算术均值（给 Σŷ）。模型选择用未 smearing 的 MAE（`t2_fit.py` L63），smearing 不当选模依据，这是对的。容量表同时给 median-type 与 smeared（`t2_eval.py` L50–58），口径分开。

**`reg_metrics` / `bootstrap_mae_ci`：没问题。** 指标全在天尺度；`sum_bias_pct = 100*(Σŷ−Σy)/Σy`（`common.py` L140–146）。bootstrap 是成对重抽样百分位 CI（同一下标抽 `y` 与 `ŷ`，`common.py` L149–152），seed 固定，各模型共用同一套重抽样下标，便于并列。

**D 的工作点纪律：没问题。** 阈值来自冻结的 `t1_operating_points.json["logreg"]["0.9"]`（`stage_D_fn_autopsy.py` L17–20），不重训；`Length_of_stay` 只进尸检描述（L4、L23、L39）。Mann-Whitney 本身用 `two-sided` + 各组 `dropna` 后比较 FN vs TP（L45–48），检验方向没有用错。

**PDP 不碰 test：没问题。** 在 val 上画（`stage6_pdp.py` L14、L28–30）。

### 应改

**1. 系数「每 SD 对剩余住院日的 %」换算对象错了（应改）**  
`t2_eval.py` L108、L112–113：

```108:108:t2_eval.py
        rows.append({..., "pct_change_remaining_LOS_per_SD": 100 * (np.exp(v) - 1)})
```

模型是 `log(1+y)`，不是 `log(y)`。`100*(exp(v)−1)` 是 **(剩余住院日 + 1)** 的百分变化，不是 `y` 的百分变化。  
真值：`(1+y)` 乘 `exp(v)`，故  
`Δy/y = [(1+y)/y]·(exp(v)−1)`，随基线 `y` 变。中位剩余大约数天时，表里的数会系统性偏低约 `1/(1+y)` 这一截。  
打印文案「每 SD 对剩余住院日的 % 影响」会把这个错数送上 slide。  
应改成列名 `pct_change_in_(LOS_remaining+1)_per_SD`，或在 train 中位数 `y` 处再乘 `(1+y)/y`。0/1 列（ICUType、`measured_*`、`MechVent_any`）经 `StandardScaler` 后仍是「每 1 SD」不是「从 0 到 1」，并列明。

**2. 全局 Duan smearing 的无偏性依赖于 log 尺度同方差；代码算了异方差却不约束容量主张（应改）**  
`t2_eval.py` L71–81 用 Spearman(`|resid|`, fitted) 做异方差检查，对象包括主模型的 log1p 残差。Duan 的单个 `S=mean(exp(r))` 假定 `r ⊥ X`。若 `heteroscedasticity_p` 很小仍把 `pred_smeared` 的 Σ 偏差读成「均值无偏的床日容量」，统计上过满。应改：容量主张必须以该检验为条件；异方差显著时改分层 smearing / 只报中位数型，或把 smeared Σ 降为敏感性。

**3. 「中位数型」表述过满（应改，解释层面）**  
`common.py` L129：`smear=1` 写成「条件几何均值（≈中位数型，MAE 最优）」。线性模型/RF 拟合的是 log1p 上的平方误差，得到的是 `E[log(1+y)|x]` 的反变换；只有 log 残差中位数为 0 时才是条件中位数。MAE 最优的点预测是分位数回归，不是 OLS/Ridge。个体读数用 unsmeared 仍然合理，但不宜写成「MAE 最优中位数」。

**4. Mann-Whitney 未校正多重比较，却输出「显著」名单（应改）**  
`stage_D_fn_autopsy.py` L44–52：对约 29 个变量做 FN vs TP 双侧 MW，然后

```52:52:stage_D_fn_autopsy.py
summary["FN_vs_TP_significant_p<0.05"] = tab[tab.FN_vs_TP_mannwhitney_p < 0.05].variable.tolist()
```

α=0.05 下期望假阳性约 1–2 个。尸检可以报原始 p 和中位数，但这个键名等于把未校正 p 当发现。应 Holm/BH，或改名为 `p_uncorrected_<0.05` 并在摘要里写明未校正。
