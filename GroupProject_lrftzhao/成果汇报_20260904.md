## 二、关键数字

### T1（test n=2,400）

| | test AUC（95% CI） | AUC-PR | Brier |
|---|---:|---:|---:|
| 只用 SAPS-I / 只用 SOFA | 0.642 / 0.622 | — | — |
| LogReg（C=0.01） | **0.847（0.825–0.867）** | 0.508 | 0.092 |
| 决策树（depth 5） | 0.788 | 0.376 | 0.107 |
| RF（400 棵） | 0.843 | 0.519 | 0.094 |
| XGBoost（depth 4） | **0.855（0.838–0.876）** | 0.516 | 0.092 |

- 四个模型 CI 大幅重叠，**复杂度买不到显著提升**；主报告用 LogReg（可解释、校准最好），XGBoost 作对照。
- 工作点在 val 上冻结：sens 0.90 的阈值 → test 灵敏度 0.87，**每 100 人告警 43 个**，PPV 0.29，漏 44/341 个死亡。"廉价第二意见"要按这个告警负担重新讲。
- 校准：LogReg 贴对角线；RF 高危段系统性低估。**排序给复核队列，个体概率不说出口。**
- 亚组：80+ 组 AUC 0.82 最低（基础率高、可分性差），要报不要藏。
- 决策树深度曲线：depth ≥ 8 后 train AUC 0.90+、val 跌到 0.75——现成的过拟合图。

### T2（test n=2,370）

| | 中位数基线 | Lasso 几何均值型（个体） | Lasso smearing 均值型（容量） |
|---|---:|---:|---:|
| MAE 天 | 7.24 | **6.56（6.15–7.04）** | 7.05 |
| Σŷ 对 Σy 偏差 | −29% | −26% | **−0.2%** |

- **本任务最重要的发现**：log1p 回归反变换是几何均值，总床日低估四分之一；Duan smearing 校正后总量几乎全对。**个体承诺看第一种读数，容量主张看第二种，不许混用**。分层 smearing 敏感性 +1.7%，结论稳。
- 按 ICU：CSRU 高估 20%、MICU/SICU 低估 5%——与打法 C 同构，容量数只能报整体。
- 剩余 ≥25 天的 10% 病人占 36% 床日，被低估 28 天；R² 全部 <0.13——**个体出院日期不可承诺**。
- 取 log 让残差偏度从 6.8 降到 0、异方差消失（LINE 那页的素材）。幸存者单独训只好 0.28 天，合并训练站得住。
- RF 回归 MAE 6.37，与 Lasso 的 CI 重叠，不显著更好。

### 差异化实验

| 打法 | 那句别组没有的话 | 数字 |
|---|---|---|
| **A** | 一个化验值都不看、只看开了哪些检查的模型，**打败了 SAPS-I** | 只看是否测过 0.696、加测量次数 **0.740** vs SAPS-I 0.642；仍低于 T1 0.847 → T1 学到了开单模式之外的生理 |
| **B** | 最后 12 小时买不到什么 | 6/12/24/36/48h：0.776 / 0.793 / 0.817 / 0.840 / 0.847，膝点 36h；6h 模型已比 SAPS-I 高 0.13 |
| **C** | 换病房：排序扛住、校准必崩 | 留出 CSRU（死亡率 4.9%）AUC 0.863 但概率高估 84%（RF 150%）；MICU 低估 10% |
| **D** | 漏掉的 44 人在 48h 里看起来就是会活的人 | GCS 15、评分低、没查乳酸，Holm 校正后 7 个变量显著；**不比抓住的人死得晚**；在 A 上的分数也和存活者一样 |
| **E** | 把「存活」放宽到出院后 30 天，排序不变 | AUC 0.847 → 0.843；sens 0.90 的 729 个误报里 55 个（7.5%）30 天内死了；主标签维持院内死亡 |
| **T3** | 第二天的数据买来 0.03 AUC | 24h 0.817 vs 48h 0.847；与 SAPS-I 的公平比较差距仍 0.17 |

## 三、贯穿的故事线（第 8 页要自己说出来）

1. **模型能打败临床评分，但打败的幅度里有一部分是 ICU 的诊疗过程而不是生理**——A（开单模式 0.74）、C（换病房校准崩）、D（漏掉的人开单也少）三个结果指向同一句话，与其被 TA 问出来，不如自己收口。
2. **排序与概率是两件事**——T1 校准、C 的 CSRU 高估、T2 的两种读数，都是同一个教训：**工作点由告警负担决定，数字要说出口先看校准**。
3. **48h 窗口的固有盲区**——D 说漏掉的人窗口内无迹象，E 说标签本身漏掉出院后早期死亡，B 说最后 12 小时已无增益：模型的边界在数据里，不在算法里。
